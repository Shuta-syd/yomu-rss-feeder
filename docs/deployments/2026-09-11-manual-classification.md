# Manual article classification

An inline ClassificationEditor opens from an article's classification chip or 分類を編集. Genre is single-select; industry/topic allow up to three choices each. Save uses authenticated article PATCH with a validated classification object, no AI request. Buttons meet 44px minimum touch height on mobile. Failed saves retain choices; cancellation discards the draft. Successful edits display 手動, persist after reload, and update article-list labels and active classification filters.

Migration 0014 adds nullable articles.manual_classification, storing the validated manual choice. ai_tags remains the effective tag list for existing filters and Memos consumers; unrelated tags are preserved. Stage 1 merges generated tags with the latest manual choice inside an immediate SQLite transaction. Manual PATCH also reads current tags and writes within a transaction. Thus an edit during an in-flight generation wins. The shared AI-result cache contains model output only, never an article's manual override, so corrections cannot leak to duplicate articles. Explicit AI regeneration still respects manual classification. No bulk propagation, retraining, or AI calls are added to manual editing.
